
# Ozone0472 - Club Espace 
## Les Hautes Ourmes - Les Chalais - Jacques Brel
## Extension MakeCode pour micro:bit V2 

Cette extension permet de programmer le capteur d'ozone DFRobot SEN0472.

![Capteur d'ozone SEN0472](sen0472.jpeg)

## Fonctionnalités

- Initialisation du capteur
- Mesure de la concentration en ozone (ppm)
- Mesure de la température (°C)
- Communication I2C
- Enregistrement des données avec le Data Logger

## Matériel nécessaire

- BBC micro:bit V2
- Capteur DFRobot SEN0472
- Câbles de connexion
